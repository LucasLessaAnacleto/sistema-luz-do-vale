    Role do Usuario: 
        coluna role da tabela USUARIO
        Admin(ROLE_ADMIN)
        normal(ROLE_USER)
    Visualizar documentos: 
        Todos podem enxergar todos os documentos

        Só é possível editar enquanto o documento não foi assinado
        Só admin e quem criou o documento
    Criar documentos:
        Admin concede permissão por TIPO_DOCUMENTO para os perfils de usuario. (tabela de PERMISSAO_PERFIL)
        Novo paciente + ficha de acolhimento do paciente também é o adm que concede por perfil (flag na tabela PERFIL)
    Excluir documento:
        Não é possivel
        Admin pode desativar o documento
    Baixar pdf do documento:
        Todos
    Finalizar documento:
        Admin e quem criou o documento
    Alterar usuario:
        Admin pode desativar usuario e alterar a senha dele
    Alterar profissional:
        O proprio profissional
    Ver logs do sistema:

PROFISSIONAL:
    sempre possui USUARIO

USUARIO:
    ROLE_USER ou ROLE_ADMIN
    sempre criado por um ROLE_ADMIN
    senha definida pelo admin
    admin pode redefinir a senha
    pode possuir PERFIL ou não
    pode ser desativado

PERFIL:
    opcional
    define permissões específicas de operação/documentos     

ROLE:
    ROLE_ADMIN + sem perfil
        é administrador
        acessa funções administrativas
        não ganha automaticamente permissões de documento do perfil

    ROLE_USER + perfil Enfermagem
        não é administrador
        ganha permissões configuradas para Enfermagem

    ROLE_USER + sem perfil
        entra normalmente
        visualiza o que qualquer usuário pode visualizar
        não cria o que depende de permissão de perfil

As regras visuais que eu congelaria
Para qualquer tela do sistema interno — Landing fica fora porque é marketing — usa estes padrões.

Largura e padding da página

Cabeçalhos/listagens:
mx-auto max-w-6xl px-5 sm:px-8

Formulários mais estreitos:
mx-auto max-w-3xl px-5 sm:px-8

Documentos/detalhes intermediários:
mx-auto max-w-4xl px-5 sm:px-8

Cabeçalho de tela
<section className="border-b border-border bg-card">
  <div className="mx-auto max-w-6xl px-5 py-6 sm:px-8 sm:py-8">

Título:
text-2xl font-semibold

Subtítulo:
mt-0.5 text-xs text-muted-foreground

Busca sempre:
mt-5

Filtros logo depois:
mt-3

Conteúdo normal
mx-auto max-w-6xl px-5 py-6 sm:px-8

Lista mais compacta:
mx-auto max-w-6xl px-5 py-4 sm:px-8

Distância entre cards:
space-y-3

Distância entre seções grandes:
space-y-6

Card padrão
rounded-2xl
border border-border
bg-card
p-5
shadow-sm
sm:p-6

Card compacto:
rounded-2xl border border-border bg-card p-4 shadow-sm

Hover de item clicável:
hover:border-primary/40

Campos de formulário
label      → text-sm font-medium
input      → rounded-xl
altura     → min-h-11 / py-3
grid       → gap-4
form       → space-y-5

Botões

Ação principal:
bg-primary
text-white
rounded-xl

Ação pequena/listagem:
rounded-full
min-h-10
px-4

Então:
Salvar / Entrar → Button normal rounded-xl
Novo / Filtros → botão pill rounded-full
Voltar → botão circular h-10 w-10

Cores

Nas telas internas, eu tentaria parar de inventar cor na mão.

Usar principalmente:
bg-background
bg-card
bg-primary
bg-secondary
bg-accent

text-foreground
text-muted-foreground
text-primary
text-primary-dark

border-border

Para alerta:
amber-50
amber-200
amber-800

A landing pode continuar com cores especiais, porque é outra proposta visual.
