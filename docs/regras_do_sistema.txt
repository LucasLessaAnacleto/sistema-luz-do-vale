PERMISSOES:
    Role do Usuario: 
        coluna role da tabela USUARIO
        Admin(ROLE_ADMIN)
        normal(ROLE_USER)
    Visualizar documentos: 
        Todos podem enxergar todos os documentos
    Editar documentos: 
        Só é possível editar enquanto o documento não foi assinado
        Só admin e quem criou o documento
    Criar documentos:
        Admin concede permissão por TIPO_DOCUMENTO para os perfils de usuario. (tabela de PERMISSAO_PERFIL)
        Novo paciente + ficha de acolhimento do paciente também é o adm que concede por perfil (flag na tabela PERFIL)
    Excluir documento:
        Não é possivel
        Admin pode desativar o documento
    Baixar pdf do documento:
        Todos
    Finalizar documento:
        Admin e quem criou o documento
    Alterar usuario:
        Admin pode desativar usuario e alterar a senha dele
    Alterar profissional:
        O proprio profissional
    Ver logs do sistema:
        Admin

            <groupId>io.github.openhtmltopdf</groupId>
            <artifactId>openhtmltopdf-core</artifactId>

        </dependency>

            <groupId>io.github.openhtmltopdf</groupId>
            <artifactId>openhtmltopdf-pdfbox</artifactId>
            <version>1.1.92</version>
        </dependency>

        <dependency>
            <groupId>org.thymeleaf</groupId>

        </dependency>



PROFISSIONAL:
    sempre possui USUARIO

USUARIO:
    ROLE_USER ou ROLE_ADMIN
    sempre criado por um ROLE_ADMIN
    senha definida pelo admin
    admin pode redefinir a senha
    pode possuir PERFIL ou não
    pode ser desativado

PERFIL:
    opcional
    define permissões específicas de operação/documentos     

ROLE:
    ROLE_ADMIN + sem perfil
        é administrador
        acessa funções administrativas
        não ganha automaticamente permissões de documento do perfil

    ROLE_USER + perfil Enfermagem
        não é administrador
        ganha permissões configuradas para Enfermagem

    ROLE_USER + sem perfil
        entra normalmente
        visualiza o que qualquer usuário pode visualizar
        não cria o que depende de permissão de perfil
