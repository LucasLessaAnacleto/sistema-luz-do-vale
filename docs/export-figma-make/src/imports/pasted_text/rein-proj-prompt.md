# Prompt para AI do Figma — Projeto ReIntegra

Crie um projeto completo de UI/UX para um sistema chamado **ReIntegra**, voltado para gestão de uma clínica/centro de reabilitação de dependentes químicos.

O projeto deve ser criado inicialmente apenas para **mobile-first**, porém pensando em um sistema web responsivo utilizado principalmente pelo celular. Não criar versão desktop neste momento.

A proposta do sistema é transformar um processo atualmente manual em um sistema moderno, humano, acolhedor, organizado e profissional.

---

# Contexto do Projeto

A instituição atendida é a **Luz do Vale**, localizada em Nova Veneza - SC.

Ela atua como centro de recuperação de dependentes químicos e possui profissionais como:

* Psicólogos
* Enfermeiros
* Psiquiatras
* Equipe administrativa
* Coordenação

Atualmente os processos são feitos utilizando:

* Papel
* Planilhas Excel
* Arquivos Word

O sistema ReIntegra será responsável por:

* Centralizar informações dos pacientes
* Organizar prontuários
* Facilitar auditorias
* Melhorar acompanhamento clínico
* Melhorar comunicação com familiares
* Reduzir trabalho manual
* Melhorar rastreabilidade de informações

O sistema deve transmitir:

* Humanização
* Segurança
* Organização
* Calma
* Confiança
* Leveza
* Profissionalismo
* Saúde e acolhimento

# Observações Importantes

* NÃO criar visual genérico.
* NÃO criar aparência antiga de sistema hospitalar.
* NÃO exagerar em informações.
* Priorizar experiência moderna.
* Priorizar legibilidade.
* Priorizar clareza.
* Priorizar humanização.
* Priorizar organização.

As telas de exemplo fornecidas podem ser utilizadas apenas como referência estrutural inicial, mas o novo design deve ser MUITO mais moderno, sofisticado e profissional.

O objetivo é criar um protótipo que pareça um produto real pronto para startup/SaaS de saúde.

O resultado final deve parecer um aplicativo premium de gestão clínica humanizada.
